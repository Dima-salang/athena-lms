# ATHENA-LMS
- for student examination and automated checking


## MAIN FEATURES
- Parallel Examination
  - Types
    - Long tests
    - Summative tests
    - Quizzes
    - Periodical
  - there are types but at the end of the day, it is just the same format.
  - Can have randomized order
  - Timed or No time
  - Schedule
  - autosaved
  - question types
    - multiple choice
    - matching
    - true or false
    - identification
    - acronym
  - one-time enable per student for enabling the test only for that student or for a specific batch of students
  - multiple sections
  - duplicate exam function for teachers where the exams can be templates
  - skipping
- Automated Checking
  - raw score with transmuted grade
  - reports and analytics
    - need to see entire class list
      - class list uploaded by adviser or admin
  - correct response for all exam types
- Account
  - Student
    - initial account
    - at login need change pass
  - Teacher
    - reports
  - change password mechanism
